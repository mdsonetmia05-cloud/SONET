# SONET Academy — Bangladesh Academic LMS

- Default student language: Bengali (Hind Siliguri). English also supported.
- Flow: Academic Year → Level → Class → Group → Subject → Chapter →
  Topic → Lesson → Materials → Assessment.
- Boards: Dhaka, Mymensingh, Rajshahi, Cumilla, Jashore, Chattogram,
  Sylhet, Barishal, Dinajpur, Madrasah Board, Technical Board.
- Programs: General, Madrasah, Technical & Vocational, English Version,
  English Medium Supplementary.
- Exams: class test, weekly, monthly, half-yearly, annual, selection,
  test exam, SSC prep, HSC prep, model test, admission test. MCQ is
  auto-graded server-side; written/CQ answers are graded manually by teachers.
- Curriculum version control: a published version is history. Create a
  new version for a new year/syllabus; do not overwrite prior years.
- Content rule: original explanations + teacher materials + licensed
  resources + links to official NCTB textbooks. No full textbook reproduction.
- References: https://nctb.gov.bd/ and https://nctb.portal.gov.bd/
